CS300 Data Structures and Algorithms Portfolio

This repository contains work I completed in CS300: Data Structures and Algorithms. Through these projects, I strengthened my understanding of data structures, algorithm efficiency, and software design using C++.

Project One
Project One focused on analyzing vectors, hash tables, and binary search trees. I compared runtime performance and memory usage to determine which data structure would be the most effective solution for a course advising application.

Project Two
Project Two is a course advising application written in C++ using a Binary Search Tree (BST). The application allows users to display courses in alphanumeric order and search for specific course information, including prerequisites.

Reflection
The goal of these projects was to find an efficient way to store, organize, and retrieve course information. By comparing multiple data structures and implementing a Binary Search Tree, I learned how the choice of data structure directly impacts performance and scalability.

One challenge I faced was implementing and testing the Binary Search Tree. I worked through these challenges by breaking the project into smaller tasks, using pseudocode, and testing each part of the program as I completed it.

This course expanded my understanding of software design by teaching me to think about efficiency and scalability before writing code. It also helped me improve my ability to write maintainable, readable, and adaptable programs.
